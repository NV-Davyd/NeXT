CARX 2 MOD / CLIENT 1.7.1 / GAME BUILD 25255628

The product name is undecided. The existing CarXTyres plugin identity and saved
account-link location are preserved by this maintenance release.

INSTALL ON ANOTHER WINDOWS PC
1. Install/update CarX Drift Racing Online 2 through Steam, launch once, then exit.
   This plugin requires game build 25255628 with the exact hashes below.
2. Open the game's folder through Steam: Properties > Installed Files > Browse.
3. If this folder already has BepInEx, copy only
   BepInEx/plugins/CarXTyres/CarXTyres.dll into the corresponding location.
   Keep the existing loader, configuration and other mods.
4. For a fresh BepInEx installation, extract this archive beside the game EXE.
   The included Unity base-library ZIP must remain zipped.
5. Launch through Steam. First launch may take longer while bindings are generated.
6. Press F10 to link the playing Steam account. Access requires owner approval:
   https://carx-mod-access.carx-mod-access.workers.dev

CONTROLS
Apostrophe (') refreshes mounted tyres; F6 saves a waypoint; F7 returns to it.
F8 opens the native dynostand while parked in a multiplayer room.
F10 opens account linking. Faster spectating uses the normal game controls.
The tyre-life display follows the game's native tyre-temperature widget.
There are five functional features plus a team watermark; existing access grants
remain compatible, including the legacy team_logo entitlement.

For rollback, close the game and replace only CarXTyres.dll with the previous
release. Do not delete BepInEx/config/CarXModAccess: it holds the local account link.
To disable the mod, close the game and move its DLL out of BepInEx/plugins.
