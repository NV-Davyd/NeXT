NeXT adds a tyre-life display, tyre refresh, waypoints, room tuning, and faster spectating to **CarX Drift Racing Online 2**.

## Install

1. Close the game. In Steam, open **Properties → Installed Files → Browse**.
2. Download the ZIP above and copy its contents into the game folder.
3. Launch the game and press **F10** to connect through Steam.

The first launch can take a little longer. Access requires approval.

**Already using BepInEx?** Copy only the mod folder from `BepInEx/plugins` into your existing `BepInEx/plugins` folder.

Your available controls are on your [account page](https://carx-mod-access.carx-mod-access.workers.dev).
